## Operating states

The five-way is numbered bridge to neck. `∥` denotes parallel pickup connection. The neck-add switch is a latching SPST.

| Position | Neck-add off    | Neck-add on            |
| -------- | --------------- | ---------------------- |
| 1        | Bridge          | Bridge ∥ Neck          |
| 2        | Bridge ∥ Middle | Bridge ∥ Middle ∥ Neck |
| 3        | Middle          | Middle ∥ Neck          |
| 4        | Middle ∥ Neck   | Middle ∥ Neck          |
| 5        | Neck            | Neck                   |

## Netlist

| Net    | Connected terminals                                                                                                                                                                                                       |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `B-H`  | Bridge coil hot; standard five-way pickup throw 1                                                                                                                                                                         |
| `M-H`  | Middle coil hot; standard five-way pickup throw 2                                                                                                                                                                         |
| `N-H`  | Neck coil hot; standard five-way pickup throw 3; neck-add SPST throw                                                                                                                                                      |
| `BUS`  | Five-way pickup pole common; neck-add SPST common; A250K volume CW/input lug; A500K tone CCW/input lug; treble-bleed parallel pair input                                                                                  |
| `TB-J` | Common far end of 1,200 pF capacitor and 150 kΩ resistor; one end of 20 kΩ series resistor                                                                                                                                |
| `OUT`  | A250K volume wiper; other end of 20 kΩ treble-bleed resistor; output jack tip                                                                                                                                             |
| `T-W`  | A500K tone wiper; 22 nF tone capacitor signal end                                                                                                                                                                         |
| `GND`  | Bridge, middle, and neck coil returns; all three isolated pickup shield leads; A250K volume CCW lug; tone capacitor return; pot cases; conductive switch chassis; cavity shield; bridge/string ground; output jack sleeve |

The treble bleed is `BUS → (1,200 pF ∥ 150 kΩ) → TB-J → 20 kΩ → OUT`. Reversing the order of the two series elements is electrically equivalent. The tone shunt is `BUS → A500K tone CCW-to-wiper resistance → T-W → 22 nF → GND`; its unused CW lug is open. The A250K audio volume divider is `BUS → CW lug / track → wiper OUT → track / CCW lug → GND`. Pot views in the drawing show the back, shaft away, lugs pointing down: left is CW, center is wiper, right is CCW.

## Functional switch contacts

One pole of a conventional two-pole Strat five-way handles the pickup selection; the second pole is unused. An ordinary five-way **bridges adjacent throws** at positions 2 and 4. A separate SPST connects `N-H` to `BUS` when neck-add is on.

| Position | Pickup pole common `BUS` contacts | SPST off                  | SPST on                         |
| -------- | --------------------------------- | ------------------------- | ------------------------------- |
| 1        | `B-H`                             | `N-H` isolated from `BUS` | `N-H ↔ BUS`                    |
| 2        | `B-H` and `M-H`                   | `N-H` isolated from `BUS` | `N-H ↔ BUS`                    |
| 3        | `M-H`                             | `N-H` isolated from `BUS` | `N-H ↔ BUS`                    |
| 4        | `M-H` and `N-H`                   | no new connection         | `N-H ↔ BUS` (already selected) |
| 5        | `N-H`                             | no new connection         | `N-H ↔ BUS` (already selected) |

The hot leads must not be joined to each other ahead of the selector. Neck-add joins only `N-H` to `BUS`. Each coil return remains grounded in every state. There is no series junction or lifted shield in this guitar.
