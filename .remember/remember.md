## Context

For Coupeville/Relay plastic-body guitars, 9–42 is the intended string set and 10–46 is the absolute maximum because the plastic body can only withstand limited string tension. This is a structural platform limit, not a setup choice and not something that can be changed by reconfiguring the guitar.
